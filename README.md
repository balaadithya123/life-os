# LifeOS (retired)

This repository contains the older Telegram-based LifeOS project. It has been retired and is no longer the active project.

As of 2026-11-06, the GitHub Actions workflows that ran scheduled Telegram work were removed, and the Cloudflare Workers `life-os` and `lifeos-agents` were deleted. The source remains in Git history for reference and recovery; it is not part of Android Agent OS.

The active project is Android Agent OS. Its production dashboard is served from the `android-agent-os/dashboard` directory in the `android-agent-platform` branch of the Android Agent OS code repository.

Do not recreate the Telegram Worker or restore scheduled workflows unless the owner explicitly asks for the legacy system to be reactivated.
