# LifeOS (retired)

This repository contains the older Telegram-based LifeOS project. It has been retired and is not the active project.

As of 2026-11-06, all GitHub Actions workflows have been removed from this repository, including Telegram polling, scheduled jobs, and Cloudflare Worker deployment hooks. The Cloudflare Workers `life-os` and `lifeos-agents` were deleted. Legacy source is retained in repository history for recovery; it is not part of Android Agent OS.

The active project is Android Agent OS in the `main` branch of [balaadithya123-lifeos-agents](https://github.com/balaadithya123/balaadithya123-lifeos-agents). Its production dashboard is served from `android-agent-os/dashboard`.

Do not recreate the Telegram Worker or restore automation unless the owner explicitly asks to reactivate the legacy system.
