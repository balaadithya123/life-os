# Feedback evidence
Add JSON files with feedback, support notes, review excerpts or analytics summaries. Do not include secrets or unnecessary personal data.

```json
[
  {"project":"my-app","category":"onboarding","title":"Users abandon registration","severity":"high","source":"weekly feedback review"},
  {"project":"my-app","category":"performance","title":"Directory loads slowly","severity":"medium","source":"analytics summary"}
]
```
Only supplied evidence is analysed; analytics integrations are not implied.
